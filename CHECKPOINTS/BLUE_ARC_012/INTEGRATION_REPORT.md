## Verification and source boundaries

The ZIP passed CRC validation. The root manifest’s size and SHA-256 entries match all eleven numbered files. The package identifies 01–06 as inherited from 011 and 07–11 as additions. The standalone 011 archive was unavailable in the inbox and Downloads, so the inherited designation is attributed to the handoff. All thirteen reissue members, including its updated README and manifest, are preserved as exact bytes. Prior checkpoints and original evidence remain in place. [Supplied manifest](../../PROVENANCE/WORKSHOP/BLUE_ARC_012/MANIFEST.json) · [Archive registration](../../PROVENANCE/SOURCE_REGISTRY.json)

The named weekdays agree with the continuous six-day ledger anchored on Day 931 = Aiven. The source uses “fifth-day” for the royal salon in its Ailor-first ordering. The existing civil and academic lists use a different starting point. Events are recorded on Aiden (951, 1005 and 1023), without renumbering civil or academic days.

The AERA reference defines a velis as a local topology formed by an Architect. File 01 applies the word to a natural anchor at the research site. Its local wording is retained and class equivalence remains OPEN. The MK727 catalogue verifies GE-0043’s directed Beam geometry, Yellow/Green industrial assignment, project/deploy activation and mixed sustain. Only the relevant identity and functional fields were used.
