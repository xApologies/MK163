# MK163 Book Blue Revision 004 — Codex integration package

**Status:** Author-selected revision prepared 2026-11-21. **Not yet pushed to GitHub.**

This package is a **scoped additive/superseding delta** to the already integrated `BOOK_BLUE_MACRO_002`, not a wholesale replacement. It consolidates:
1. King's Tournament recurrence changed from **four years to three years**.
2. Kaira's second King's Tournament placed **at the end of Book Blue Red Arc**, after the Violet Realm return.
3. Black Singularity bonds grant Kaira's six Black companions the **exception** to visit other chromatic realms with her; Nyx does not qualify.
4. The previously prepared **Book Blue Leviathan maritime support 003** addition, included here so this single package suffices even if 003 has not been pushed.

The existing Orange through White arcs and Cabal of Maegi revelation are retained. **Do not infer that this ZIP was pushed.**
