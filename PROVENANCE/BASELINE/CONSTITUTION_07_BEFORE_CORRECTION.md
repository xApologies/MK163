# Naming constitution

Preserve AERA's canonical terminology and exact spellings. Examples: `maege` singular, `maegi` plural, `vaen`, `domai`, `velis`, `raeon`, `Aineth` (enchanting), `Ain` (enchantment), `Aenith` (enchanted object). Character name `Kira` is used in this project. When a source conflicts, record the discrepancy and consult the current author-established choice. Do not invent replacements.
