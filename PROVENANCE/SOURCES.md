# MK163 source navigation

The structured register is `SOURCE_REGISTRY.json`. Topic records identify their own sources and embedded author passages. Original PDFs, images and API archive are preserved under `SOURCE_DOCUMENTS`, with SHA-256 identities in `ATTACHMENT_MANIFEST.json`. The full eight prophecy manuscripts and their Git blob identities are indexed in `PROPHECY_SOURCE_MANIFEST.json`.

The evidence journal is `WORKSHOP/AUTHOR_EVIDENCE_JOURNAL.md`; its machine-readable equivalent is `WORKSHOP/AUTHOR_SOURCE_RECORDS.jsonl`. The source records are original author passages, not claims that all skipped assistant/tool messages were exported as a complete raw chat transcript.

Current MK163 interpretation lives in the detailed World Clock topic files. Source archives are not independent permission to import old plots, rename Kaira, execute historical scripts or replace current rules.
