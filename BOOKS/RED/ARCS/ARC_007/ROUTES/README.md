# White routes

Eight unique dungeon route registers each retain A–E. The B03 qualifier selects B; the later Stage Two visit uses A from the same B03 register (14.689 mi to the 11.5-mile Blue boundary on G048–B011). B02 selects A; Blue V2 C; Blue V1 D; Green V2 B; Green V1 B; Violet V1 C; royal Violet V2 A. Thus nine race occurrences use eight dungeon registers; do not manufacture a ninth graph. Local V1/V2 restart per political domain. Threshold endpoints name the outgoing passage, not a mandatory arrival at the terminal node.
