# Continuity constitution

Record significant events with stable IDs, chronological placement (or explicitly unknown), involved characters, entry state, exit state, and dependencies. Track equipment, relationships, status, and locations when narratively relevant. Distinguish Git commit time from in-world time. The inherited calendar is 31-hour days, 360-day years, four 90-day seasons, six-day weeks; month definitions remain pending verification. Avoid silently guessing dates.
