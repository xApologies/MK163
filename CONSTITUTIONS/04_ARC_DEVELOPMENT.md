# Arc development constitution

Books are RED, ORANGE, YELLOW, GREEN, BLUE, VIOLET, WHITE. Each book has zero or more arcs (`ARC_001`, `ARC_002`, ...), with a stable ID such as `MK163-RED-ARC-001`. Arcs are variable-length plot units, not fixed chapter counts. Every populated `ARC.md` must contain:

1. Arc identity (book, number, working title)
2. Narrative objective
3. Entry state
4. Principal conflict
5. Major events
6. Exit state
7. Dependencies (World Clock and preceding events)
8. Status (concept, outlined, drafting, revised, locked)

Chapters and scenes can be planned within an arc as needed. Do not precreate unapproved arcs or fabricate chapter counts. An arc's exit state must reconcile with continuity.
