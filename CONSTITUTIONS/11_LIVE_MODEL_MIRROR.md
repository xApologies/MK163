## Canon versus prose
Keep one active canonical factual owner. An arc references that fact; a chapter realizes it in prose; continuity records its persistent effect. Store source quotes as evidence, not competing active definitions. A planned future acquisition must not appear in the character's present possessions. Character knowledge is not identical to the reader's knowledge or the author's plan.

## Arc contract
Each populated arc has stable ID (example MK163-GREEN-ARC-001), book/number/title, narrative objective, entry state, principal conflict, major events, exit state, dependencies and status. Any number of chapters/scenes may realize an arc. Do not invent outlines or chapter counts when creating a scaffold. “Possible Arc2/3” is not an approved complete Arc2 or Arc3.

## ZIP export
Compare the current path-aligned working model to the actual target Git tree. Deliver every new or changed substantive record, not just a list of headings or URLs. Include full evidence, original supplied sources and visual references relevant to the stated scope, correction and decision registers, and a path/hash manifest. An unchanged exhaustive source already safely present need not be duplicated in every later delta; document the dependency by verified hash/path. The first substantive preservation delivery must not substitute an eight-paragraph summary for the established model.

Use the author's familiar handoff: ZIP in ignored _inbox; execution.md at archive root; Codex applies to this same repository. No unrequested repository creation, migration framework or iCloud reorganization. Git does not execute Markdown itself: Codex reads the authorized instructions and performs file/Git operations.

## Completion and future resumption
Validate actual file content and coverage before claiming success; push success alone proves transport, not semantic preservation. Preserve source originals and original wording. Stable IDs, explicit current paths and unresolved boundaries let the next thread resume without forcing the author to repeat established work. There is no claim of magical persistent memory beyond these files.
