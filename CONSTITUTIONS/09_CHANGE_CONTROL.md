# Change control constitution

Classify each change as new canon, canon correction, proposed concept, prose-only revision, source reference, or constitutional amendment. Record rationale and provenance. Changes to locked facts require explicit author approval. Keep checkpoint summaries lightweight and link to Git commits; avoid embedding entire delivery ZIPs inside tracked folders. No destructive operations without review.

## Non-destructive live-model updates

No live-model import may shorten or remove previously established mechanisms, descriptions, examples, exceptions, or provenance for brevity. A correction or supersession must retain an audit trail of the prior statement, the author's replacement, source and reason; the current canon should remain unambiguous. An import must diff against the existing repository and against the available workshop coverage inventory. Treat any unaccounted deletion or semantic loss as a blocking conflict.
