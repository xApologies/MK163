# Source audit and recovery boundaries

The exact supplied cumulative checkpoint 004 was inspected locally. Its ZIP integrity check passed. All files listed in its inherited manifest match their listed SHA-256 hashes. The inherited manifest is still labeled for checkpoint 002 and does not enumerate 16 later 003/004 payload files. Those files are present; this is incomplete manifest coverage, not evidence of corruption or loss. The original archive was not modified.

The original generator, static renderer, viewer builder, and graph validator are present. The generator reproduces all eight graph outputs byte-for-byte in the recorded tested environment. The static renderer rebuilds its eight map pages, and the viewer builder rebuilds its offline HTML.

The environmental tables and images are present, but their original generation script and exact difficulty thresholds are not. This package preserves those outputs and explains future environmental-generation procedure separately. The original compiled PDF guide-wrapper assembly script is also absent; the actual graph-map renderer is present.

The environmental companion remains proposed. Its entrance node R001 has a generated forest-region membership that needs author review. The G062 formation hotspot remains a proposal. Prior Blue Arc research/rescue sites have not been arbitrarily anchored to nodes. No current remote repository HEAD was fetched for this methodology task.

The reference trial route to B041 is an explicit later author lock. It supersedes the earlier no-route-selected wording only for that itinerary; it does not approve every environmental proposal or establish an official tournament marker.
